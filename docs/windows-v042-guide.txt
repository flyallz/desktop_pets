猫咪桌宠 v0.4.2 · 发给朋友的成品

先退出旧版，再双击 EXE。照片、图标和动作均已内置，不用安装制作工具。
适用 Windows 10 / 11 64 位，需系统 .NET Framework 4.8。

• 单击摸猫，按住拖动。
• 双击切换照片造型，右键“换造型”可直接选六种造型。
• 原有走路、伸懒腰、睡觉和自动活动保留；动作结束后回到所选照片。
• 右键“和猫咪聊天”随时打开聊天窗口。
• 第一次在“聊天设置”填写自己的 DeepSeek API Key；不要把密钥发给别人。
• Enter 发送，Shift + Enter 换行；“停止回复”取消等待。
• “打个招呼”请求一句问候；设置里可开启每 15 / 30 / 60 / 120 分钟的主动问候，默认关闭。
• 隐藏、暂停、睡觉或聊天时不主动问候。
• 右键或右下角托盘菜单可隐藏、显示和退出。

密钥加密保存在当前 Windows 账户的 %LOCALAPPDATA%\PhotoCat\settings.json。
只发这个 EXE 给朋友，不需要发送设置文件。没有密钥也可离线玩桌宠。
聊天和开启的主动问候会调用 DeepSeek，费用由对应账户承担；照片和屏幕不上传。
聊天只保留本次运行的对话，退出桌宠后清除。程序没有内置任何真实密钥。

六种造型来自猫主人真实照片；个别照片保留原图中的身体裁切。
其他照片保持静态外观，原版坐姿保留眨眼等局部动作。
原有动作使用 v0.4 的素材，不会自动生成每套照片对应的走路画面。

本机回归和模拟接口验证已通过；真实 DeepSeek 在线回复需填写有效密钥后使用。

## 播放实现

`SpriteAnimation.cs` 在启动时解码图集并缓存 57 个裁剪帧及透明度。每次更新只选择已有帧，使用 WPF 2D 绘制，不重复加载文件、不调整窗口尺寸，也不对左右行走素材额外镜像。鼠标命中从当前显示帧的透明度读取。

所有动作共用统一缩放与脚底基线。图片的生成差异仍会造成少量毛发、脸部与步态变化；这不是真实运动捕捉，不声称每个动作已达到无差异的连续视频效果。

旧照片造型保留原来的局部动画。自选照片只使用自己标记的眼睛、耳朵与尾巴，不会变成示例猫的全身动作。DeepSeek 设置和本地照片库继续复用，更新不会清空它们。

## 来源与授权

由 Codex 内置 imagegen 参考用户朋友的猫咪照片生成，狗狗精灵图只用于排列方式参考。生成结果原本带有棋盘背景，经已有的本地 IS-Net 模型去背景，再修正跨格轮廓、统一缩放和对齐。

本次发布加入衍生透明图集、预览与制作提示词。原始房间照片、下载模型、开发环境、个人设置及 API 密钥不在源码仓库中。

实际提示词见 [sprite-actions-prompt.txt](sprite-actions-prompt.txt)。

## 验证边界

完整 EXE 的 `--self-test` 会保留旧版照片编辑与模拟聊天检查，并输出 `sprites/` 下 57 张实际 WPF 渲染图，检查每帧轮廓未裁切、透明度、鼠标命中、固定窗口尺寸、左右移动方向、手动动作、自动轮换、暂停/拖动/菜单/隐藏和睡醒流程。

像素对比检查固定使用 WPF 软件渲染；旧睡醒合成允许最多 64 个边缘像素出现不超过 2/255 的通道舍入差异，更大的变化仍会失败。普通运行沿用系统渲染设置。实时计时器检查使用真实 WPF 调度器。聊天只用本地模拟接口验证，本轮没有提供真实 DeepSeek API Key。其他电脑、实体鼠标操作及混合 DPI 多屏仍需要实机试用。

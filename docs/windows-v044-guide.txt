猫咪桌宠 v0.4.4 · 给朋友的使用说明

先从猫咪右键菜单退出旧版，再双击新版 EXE。
如果收到的是 ZIP，先“全部解压”，再打开里面的 EXE。
适用 Windows 10 / 11 64 位，需系统 .NET Framework 4.8。

自己添加照片
1. 右键猫咪 → 换造型 → 添加自己的照片。
2. 选择 JPG / PNG，程序会自动去掉背景。第一次会准备工具，稍等即可；以后可离线使用。
3. 需要时点“放大”。眼睛沿两个眼角拖线；尾巴从根部拖到尖端；耳朵从根部拖到耳尖。看不到或闭着的部位可以跳过。
4. 点“看看它动起来”。标错可清除重画，背景残留可擦掉，擦多了可恢复或撤销。
5. 起一个名字，点“保存并用这个造型”。之后双击猫咪就能切换，重启也会保留。

自己的照片会原地陪伴、呼吸，并按标记眨眼或摆尾。
内置六种造型保留原有活动；自选照片不会切成内置猫咪的走路画面。
右键“换造型”还可以调整、改名或删除当前自选照片。删除只移除桌宠副本，不删除原照片。

平时使用
• 单击摸猫，按住拖动；双击换造型。
• 右键可改大小、暂停动作、隐藏或退出。隐藏后可从右下角托盘恢复。
• 右键“和猫咪聊天”打开聊天窗口。
• 第一次在“聊天设置”里填写自己的 DeepSeek API Key。没填也能用照片和桌宠功能。
• 聊天 Enter 发送，Shift + Enter 换行，“停止回复”取消等待。
• “打个招呼”立即请求问候；主动问候默认关闭，可在聊天设置里开启。

照片只在电脑上处理，不会上传；抠图不需要 API Key。
完整文件约 203 MB，已包含照片工具，不用另装 Python 或配置环境。
照片保存在 %LOCALAPPDATA%\PhotoCat\photos。更新 EXE 不会清空，复制这个文件夹即可备份。
首次准备的工具在 %LOCALAPPDATA%\PhotoCat\tools，后续自动复用。
不要给别人发送自己的 settings.json；只发 EXE 或成品 ZIP 即可。
聊天会请求 DeepSeek，费用由填入密钥的账户承担；密钥经当前 Windows 账户加密保存。

如果抠图留下杂物，先擦一擦再保存；也可以换一张主体更清楚的照片。
本机功能与模拟聊天检查已通过。真实 DeepSeek 回复需有效密钥；不同电脑和鼠标操作手感还需实际试用。
